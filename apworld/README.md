# poy-archipelago (apworld)
The apworld for poy-archipelago.

# Building from source
To build the apworld from source, you can
either run the build script directly, or use nix-shell.

In either case, the generated apworld can be found in `build/`.
(The same directory you run the script/nix-shell in).

## Running directly
```sh
cd build/
./build.sh
```

## Using nix-shell
```sh
cd build/
nix-shell
```
